# Lap Analysis & Prediction Dashboard (LAPD)

The LAPD is a Streamlit-based prototype developed as part of the dissertation titled "Machine Learning Analysis of the Effects of Tyre Characteristics and Weather Conditions on Formula 1 Performance."

The dashboard supports exploratory Formula 1 performance analysis and lap-time prediction using tyre compound, estimated tyre age and circuit information.

The prediction component uses a trained Linear Regression model. Weather conditions are explored separately and are not direct inputs to the prediction model.

The prototype is intended for academic research and demonstration purposes.
